# Ordinary-document source corpus

Twelve deliberately authored clean office/prose pages form a separate candidate pool from the difficult editorial V2 set. The set contains a service letter, minutes, a two-page handbook, a service report, printed email, invoice, purchase order, account statement, blank application, packing list and stock report. They are fictional original compositions; no real customer information, third-party page images, model outputs, scans or capture variants are included.

`finalize.py --root <durable-root> --render` builds both author modules through the existing source-first Page framework. It saves commands, glyph boundaries, table cells, explicit prose/math/table applicability, expected Markdown, source/reference hashes and construction-confidence receipts before raster publication. The contact sheet supplements full-resolution inspection. Reading order and heading ranks remain unvalidated; expected Markdown is a review serialization, not a content-score admission.

Provide staged contribution and font-license evidence under `publication/`, inspect the pages, then use `finalize.py --root <durable-root> --freeze`. It checks source artifacts and native glyph overlaps, groups actual documents/template instances/exact image duplicates, and selects eight development/four holdout pages without reading predictions. The two-page handbook stays together. Generic Page/font utility reuse does not imply a common source-template instance. Frozen manifests use absolute image/source/reference paths so strict files work independently. The source lock rejects later changed annotations and prevents rerendering locked sources.

The font files are local renderer dependencies referenced by hash. They are not exported. Original contributions use the coordinator's staged CC-BY-4.0 candidate policy; generator code and font programs retain their individual licenses. The rights receipt is evidence for a reviewable candidate, not public release or a legal guarantee.

Run `TMPDIR=<agent-scratch> python test_finalize.py` for source-group closure, immutable-label and overlap-gate checks. Prepare the separate integrity gate with `../corpus_v2/integrity.py --root <durable-root> --repo <core-repo> --frozen-directory frozen-common`. Model results never alter frozen source bytes or splits. Report unique form/multipage holdout gaps explicitly.
