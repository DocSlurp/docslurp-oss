# DocSlurp trademark policy (draft)

"DocSlurp", the DocSlurp logo and related marks identify the DocSlurp service and software. The source code is available under the licenses in [LICENSE](LICENSE); those licenses do not grant any right to use the DocSlurp name or logo, except as described here.

**Permitted without asking**

- Stating accurately that your software works with, integrates with or is compatible with DocSlurp ("works with DocSlurp", "DocSlurp-compatible").
- Naming the project in documentation, blog posts, talks and package dependency lists.
- Using the unmodified name to refer to the unmodified software in a self-hosted deployment you run for your own use.

**Not permitted without written permission**

- Naming a fork, product, hosted service, company or domain "DocSlurp" or something confusingly similar.
- Implying official endorsement, partnership or affiliation.
- Using the logo or visual identity in a way that suggests your offering is the official one.

If you distribute a modified version or offer it to third parties as a service, rename it and remove the logo. SSPL section 13 obligations for hosted services are separate from this policy.
